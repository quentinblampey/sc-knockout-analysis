# Single-cell knockout analysis

Short analysis/notebooks to assess the impact of synthetic knock-outs on foundation models embeddings.

## Getting started

Use [`uv`](https://docs.astral.sh/uv/getting-started/installation/) to create a new environment with our dependencies.

```sh
git clone https://github.com/quentinblampey/sc-knockout-analysis.git
cd sc-knockout-analysis

uv sync
```

Then, run the different notebooks one by one.
